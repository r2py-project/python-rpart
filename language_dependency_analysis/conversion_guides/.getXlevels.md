# Conversion Guide: `.getXlevels` (R `stats` Package)

---

## 1. Overview of `.getXlevels` in R

`.getXlevels` is an internal (non-exported) function in R's `stats` package. Its purpose is to extract the factor levels (and, for character vectors, the implicitly derived levels) for every predictor variable referenced in a model's `Terms` object, sourcing the actual data from a fitted model frame `m`.

Its full source, retrieved directly from the R runtime, is:

```r
function(Terms, m) {
    xvars <- vapply(attr(Terms, "variables"), deparse2, "")[-1L]
    if ((yvar <- attr(Terms, "response")) > 0)
        xvars <- xvars[-yvar]
    if (length(xvars)) {
        xlev <- lapply(m[xvars], function(x)
            if (is.factor(x))    levels(x)
            else if (is.character(x)) levels(as.factor(x)))
        xlev[!vapply(xlev, is.null, NA)]
    }
}
```

**What it does, step by step:**

1. Extracts the names of all variables appearing on the right-hand side of the model formula from the `"variables"` attribute of the `terms` object (`Terms`). The `[-1L]` drops the language-level call object at position 1.
2. Removes the response variable (identified by `attr(Terms, "response")`) so that only predictor (X) variables remain.
3. For each predictor, inspects the corresponding column in the model frame `m`:
   - If the column is a **factor**, it returns `levels(x)` — an ordered character vector of all factor levels.
   - If the column is a **character** vector, it coerces it to a factor and returns the resulting levels (sorted alphabetically).
   - For any other type (numeric, logical, etc.), it returns `NULL`.
4. Drops all `NULL` entries, returning only a named list whose entries correspond to the categorical/factor predictors.

**Inputs:**
- `Terms`: a `terms` object (typically obtained via `attr(model_frame, "terms")`), carrying the formula structure, variable names, and response indicator.
- `m`: a `model.frame` — a data frame where each column is a processed predictor or response, in the form required by the model formula.

**Output:**
- A named list of character vectors. Each name is the variable name of a factor or character predictor; each value is its vector of levels. Variables that are purely numeric/logical produce no entry. Returns `NULL` implicitly if no categorical predictors exist.

## 2. Contextual Usage Analysis

### Location

- **File:** `rpart/R/rpart.R`
- **Function:** `rpart`
- **Line:** 82

### Surrounding code (lines 22, 31, 82–89, 294)

```r
Terms <- attr(m, "terms")          # line 22 — extract the terms object
...
X <- rpart.matrix(m)               # line 31 — numeric predictor matrix
...
xlevels <- .getXlevels(Terms, m)   # line 82 — extract factor levels per predictor
cats <- rep(0L, ncol(X))
if (!is.null(xlevels)) {
    # xlevels may include factors that were dropped from X (e.g. via ". -zed")
    indx <- match(names(xlevels), colnames(X), nomatch = 0)
    cats[indx] <- (unlist(lapply(xlevels, length)))[indx > 0]
}
...
if (!is.null(xlevels)) attr(ans, "xlevels") <- xlevels   # line 294 — stored on the fitted object
```

### Pattern and data types

- `Terms` is a `terms` object (`class "terms"`), produced by calling `attr(m, "terms")` on the model frame `m`.
- `m` is a `data.frame` (the model frame), produced by `stats::model.frame()`. Its columns are typed: factor columns carry `levels` metadata, numeric columns do not.
- The result `xlevels` is either `NULL` (no factor predictors) or a **named list of character vectors**, one entry per factor/character predictor.
- `xlevels` serves two downstream purposes:
  1. It populates `cats[indx]` — the per-variable count of categories, passed as `ncat` to the C routine `C_rpart`.
  2. It is attached to the final `rpart` fitted-object as the attribute `"xlevels"`, enabling `predict.rpart` to validate new data at prediction time.

## 3. Python Conversion Strategy

The Python equivalent must replicate the behaviour of `.getXlevels` in the context of a scikit-learn / pandas-based rpart port. The closest idiomatic Python constructs are:

- **`pandas.Categorical` / `pandas.CategoricalDtype`** for representing factor columns (preserving an explicit ordered list of levels).
- **`pandas.DataFrame`** as the direct equivalent of R's `model.frame` — columns can be inspected for `dtype` and `cat.categories`.

No `numpy` or `scipy` is needed here because the function is purely about metadata extraction (string level lists), not numerical computation. `pandas` is the right library because it has first-class support for categorical dtype, directly mirroring R's factor.

The R `terms` object's role is replicated in Python by maintaining:
- A list of predictor column names (equivalent to `xvars` after response removal).
- Knowledge of which column is the response (to exclude it).

## 4. Step-by-Step Conversion Examples

### 4.1 The Single Distinct Usage

**Locations:** `rpart/R/rpart.R`, function `rpart`.

#### Original R Context

```r
# Types:
#   Terms  : terms object  (attr of a model.frame)
#   m      : data.frame    (the model frame; columns may be factor, numeric, etc.)
#   xlevels: named list of character vectors, or NULL

Terms   <- attr(m, "terms")
xlevels <- .getXlevels(Terms, m)

# xlevels might look like:
# list(
#   Species   = c("setosa", "versicolor", "virginica"),
#   Color     = c("blue", "green", "red")
# )

# Downstream use 1 — count categories per predictor column in X
cats <- rep(0L, ncol(X))
if (!is.null(xlevels)) {
    indx <- match(names(xlevels), colnames(X), nomatch = 0)
    cats[indx] <- (unlist(lapply(xlevels, length)))[indx > 0]
}

# Downstream use 2 — attach to fitted object
if (!is.null(xlevels)) attr(ans, "xlevels") <- xlevels
```

#### Python Equivalent

```python
import pandas as pd
from typing import Optional

def get_xlevels(
    predictor_names: list[str],
    m: pd.DataFrame,
) -> Optional[dict[str, list[str]]]:
    """
    Python equivalent of R's .getXlevels(Terms, m).

    Parameters
    ----------
    predictor_names : list[str]
        Names of predictor (non-response) columns to inspect.
        In rpart, this is derived from the formula's right-hand side,
        corresponding to the xvars extracted from attr(Terms, "variables")
        after removing the response variable.
    m : pd.DataFrame
        The model frame. Categorical/factor columns must be represented
        as pandas Categorical dtype (pd.CategoricalDtype); character
        vectors that were coerced to factor in R should also be Categorical.

    Returns
    -------
    dict[str, list[str]] or None
        Named mapping from predictor name to its ordered list of levels,
        for every column whose dtype is pandas Categorical.
        Returns None if no categorical predictors exist.
    """
    xlev: dict[str, list[str]] = {}
    for col in predictor_names:
        series = m[col]
        if hasattr(series, "cat"):
            # pandas Categorical — directly mirrors R factor with levels()
            xlev[col] = list(series.cat.categories)
        elif pd.api.types.is_string_dtype(series) or pd.api.types.is_object_dtype(series):
            # character vector in R: coerce to factor then take levels (sorted)
            levels = sorted(series.dropna().unique().tolist())
            if levels:
                xlev[col] = levels

    return xlev if xlev else None


# -----------------------------------------------------------------------
# Usage in the rpart Python port — mirrors the rpart() R function body
# -----------------------------------------------------------------------

# Assume `m` is a pd.DataFrame model frame, `X` is a numeric np.ndarray,
# `x_columns` is the list of predictor column names in X order,
# and `predictor_names` comes from parsing the formula's RHS.

xlevels = get_xlevels(predictor_names, m)

# Downstream use 1 — count categories per predictor column in X
import numpy as np
cats = np.zeros(len(x_columns), dtype=np.int32)
if xlevels is not None:
    for i, col in enumerate(x_columns):
        if col in xlevels:
            cats[i] = len(xlevels[col])

# Downstream use 2 — attach to the fitted rpart object
#   (stored as an attribute on the result dict/object)
if xlevels is not None:
    ans["xlevels"] = xlevels
```

#### Explanation

| R concept | Python equivalent | Notes |
|---|---|---|
| `terms` object + `attr(Terms, "variables")` | `predictor_names: list[str]` | In the Python port, the formula parser produces a list of RHS variable names directly, eliminating the need for a `terms` object. |
| `attr(Terms, "response")` exclusion | Pass only predictor names (response already excluded by caller) | The caller is responsible for excluding the response column, just as `.getXlevels` removes it via `xvars[-yvar]`. |
| `is.factor(x)` + `levels(x)` | `hasattr(series, "cat")` + `series.cat.categories` | `pd.Categorical` columns have a `.cat` accessor; `.cat.categories` is an `Index` of the levels in their defined order, matching R's `levels()`. |
| `is.character(x)` + `levels(as.factor(x))` | `is_string_dtype` or `is_object_dtype` + `sorted(unique())` | R's `as.factor` on a character vector sorts levels alphabetically; Python replicates this with `sorted(...unique())`. |
| `xlev[!vapply(xlev, is.null, NA)]` (drop NULLs) | Only add to dict when levels are found | The `if levels:` guard and the final `if xlev else None` mirror the NULL-filtering. |
| `unlist(lapply(xlevels, length))` for `cats` | `len(xlevels[col])` per column | Direct length of a Python list replaces `length()` on each R character vector. |
| `attr(ans, "xlevels") <- xlevels` | `ans["xlevels"] = xlevels` | Stored as a regular dict key on the Python result object rather than an R object attribute. |

**Key nuance — level ordering:** R's `levels()` on a factor returns levels in the order they were defined when the factor was created (not necessarily alphabetical). When constructing the model frame in Python, `pd.Categorical` columns must therefore be created with an explicit `categories` argument matching the intended order, so that `series.cat.categories` faithfully reproduces R's `levels()` output.
